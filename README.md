
# UniPath

A university and scholarship discovery platform designed to help students explore higher education opportunities and plan their study-abroad budgets.

## Features

- Search universities by name, location, and degree program
- Compare estimated tuition and scholarship opportunities
- Plan university expenses
- Responsive interface for desktop and mobile

## Technology Stack

- Frontend: React, JavaScript, CSS
- Backend: Node.js and Express (planned)
- Database: PostgreSQL (planned)

## Project Status

The initial frontend prototype is complete. Backend development, database integration, and verification of university information are planned.

## Getting Started

1. Clone this repository.
2. Open the `frontend` directory.
3. Install dependencies using `npm install`.
4. Start the development server using `npm run dev`.

## Data Accuracy

University costs and scholarship amounts must be verified against official university sources before being used for application decisions.
